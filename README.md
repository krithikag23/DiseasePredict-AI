# 🩺 DiseasePredict AI — Diabetes Risk Classifier

DiseasePredict AI is a machine-learning powered health prediction tool that estimates whether a person is at **high risk of diabetes** based on medical indicators.

This project uses a **built-in diabetes dataset** from Scikit-Learn — so **no dataset download needed**!

---

## ✨ Features

- 🧠 Machine Learning with Random Forest
- 🎯 High accuracy classification
- 🌐 Streamlit web interface
- 🔢 Predicts risk % with confidence score
- 🏥 Real medical features used for prediction
